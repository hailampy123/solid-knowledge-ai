# Orca Behavior and Communication

## Communication

Orcas communicate using clicks, whistles, and pulsed calls. Each pod has a
distinct set of calls — a dialect — that is learned and passed down across
generations. Researchers use these dialects to tell pods apart.

## Echolocation

Orcas use echolocation to navigate and hunt. They emit clicks and interpret the
returning echoes to locate prey, even in dark or murky water.

## Hunting

Hunting is highly coordinated. Some pods beach themselves temporarily to catch
seals; others create waves to wash prey off ice floes. These techniques are
culturally transmitted within the pod.
